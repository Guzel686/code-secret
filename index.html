Code secret en couleurs

Quatre couleurs à retrouver. Dix essais pour trouver leur ordre.

Les règles

Le code caché contient quatre couleurs parmi rouge, bleu, vert, jaune, orange et violet. Une couleur peut apparaître plusieurs fois.

Après chaque essai, deux nombres vous aident :

  • Bien placées : bonne couleur à la bonne position.
  • Mal placées : bonne couleur à une autre position.

Chaque couleur du code compte une seule fois. Les indices ne désignent aucune position. Trouvez les quatre positions en dix essais maximum pour gagner.

    Comment jouer

    Retrouvez un code caché de quatre couleurs, parmi rouge, bleu, vert, jaune, orange et violet. Une couleur peut se répéter ; le code reste fixe pendant la partie.

    Choisissez les quatre positions de gauche à droite. Touchez une position pour la modifier, puis une couleur. Vous pouvez tout modifier avant de valider.

    Bien placées : bonne couleur à la bonne position.
    Mal placées : couleur présente à une autre position.

    Les bien placées sont comptées d’abord, puis les mal placées parmi les occurrences restantes. Chaque occurrence compte une seule fois. Les indices ne désignent pas les positions.

    Vous avez dix essais. Une proposition incomplète est refusée sans consommer d’essai. Quatre bien placées donnent la victoire, même au dixième essai ; sinon, la partie est perdue après dix essais.

    Après la fin, vous ne pouvez plus proposer de code. L’historique reste consultable dans sa zone défilante. « Nouvelle partie » tire un code et remet tout à zéro.

    Repères : R = rouge · B = bleu · V = vert · J = jaune · O = orange · Vi = violet. Les noms restent aussi affichés sous la palette.

    Clavier : Tab pour naviguer, Entrée ou Espace pour choisir. Échap ferme ces règles.
